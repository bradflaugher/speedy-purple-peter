# SPEEDY PURPLE PETER world metatiles (16x16 level cells, see src/core/tiles.h).
#
#   .  colour 0  the sky (white on DMG, deep space navy on CGB)
#   o  colour 1  light        +  colour 2  mid        #  colour 3  dark / outline
#
# @meta NAME... pal=P [pals=TL,TR,BL,BR] [frames=4]
#     One or more metatiles drawn side by side / stacked (16x16 cells, names row-major,
#     "-" = a context cell that is not emitted). Spaces in pixel rows are ignored.
#     frames=4: one metatile with 4 animation frames side by side (all 4 quarters animate).
# @alias NAME = OTHER
#
# Palettes: SKY GROUND BRICK GOLD TUBE DECOR HUD POLE (palettes.txt).
# Identical 8x8 tiles are stored once. Tubes must not use colour 0 (checked).
#
# Lighting is from the top left everywhere. Foreground solids (ground, blocks, tubes, hull)
# use all three colours with dark outlines; background decor (hills, nebulae, crystals,
# planet) keeps to colours 1-2 so that on the DMG it stays light grey behind the
# black-outlined sprites.
