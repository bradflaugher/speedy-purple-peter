# SPEEDY PURPLE PETER sprites (8x16 OBJ mode). File order = VRAM order.
#
#   .  colour 0  transparent      o  colour 1  light
#   +  colour 2  mid (main)       #  colour 3  dark outline
#
# @sprite SPR_NAME from=T_x copies a metatile's pixels (no rows follow).
# @sprite SPR_NAME, then 16 (or 32) rows of 8 or 16 pixels. Every frame faces RIGHT and stands
# on its bottom pixel row (checked). Tiles are emitted per 16-px band, per 8-px column, top
# then bottom: 16x16 = left N, right N+2; 16x32 = TL N, TR N+2, BL N+4, BR N+6.
# Outlines are colour 3 so silhouettes read on the white DMG sky and the navy CGB sky.
