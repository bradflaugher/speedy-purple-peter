# Module contracts

SPEEDY PURPLE PETER is split along three contracts so the pieces can be built and tested
independently:

- `src/core/tiles.h` — level cell IDs (`T_*`), shared by the simulation, the asset generator and
  the renderer.
- `src/gb/assets.h` — generated by `tools/gen_assets.py` from `assets/*.txt` (the art).
- `src/gb/sound.h` — the sound engine API (`src/gb/sound.c`).

The simulation (`src/core/`) never includes either of the Game Boy headers.

## Assets (`src/gb/assets.h` / `src/gb/assets.c`, generated)

`tools/gen_assets.py` (stdlib-only Python 3, deterministic: same input gives byte-identical
output) reads `assets/*.txt` (hand-editable ASCII art) and writes `src/gb/assets.c` and
`src/gb/assets.h`. The generated files are committed. `tests/test_assets.py` checks the pipeline.

The data lives in a switchable ROM bank (`#pragma bank 255`, `BANKREF(assets)`): bank-0 code
reads it with `BANK(assets)` switched in, and the tables the renderer needs every frame
(`mt_tiles`, `mt_attr`, `font_map`, the animation frames) are copied to RAM at load. Animated
tiles come in groups of 4 consecutive tile numbers (the supply pod, then the star bit).

The art is a space-themed spin on a classic side-scrolling platformer. No existing game's
characters or graphics are copied: everything is original.

### VRAM plan (DMG and CGB)

- LCDC: BG and window use the 0x8800 tile addressing (LCDC.4 = 0), sprites are 8x16 (LCDC.2 = 1).
- **Sprites:** tile numbers 0..207 (0x8000-0x8CFF), i.e. 104 8x16 objects.
- **BG + window:** the world tileset is at most **176** tiles. Generated BG tile *numbers* are
  already mapped to VRAM: list index `i` gets number `i < 128 ? i : i + 80`, i.e. numbers
  0..127 (0x9000-0x97FF) and 208..255 (0x8D00-0x8FFF). The loader is:

  ```c
  set_bkg_data(0, BG_TILES_LO, bg_tiles);                       /* numbers 0..127 */
  if (BG_TILES_HI) set_bkg_data(208, BG_TILES_HI, bg_tiles + BG_TILES_LO * 16);
  ```

```c
#include <stdint.h>
#include "tiles.h"                 /* T_COUNT */

/* ---- world BG tileset (also used by the HUD window and menus) ---- */
#define BG_TILE_COUNT ...          /* <= 176 */
#define BG_TILES_LO   ...          /* min(BG_TILE_COUNT, 128) */
#define BG_TILES_HI   ...          /* BG_TILE_COUNT - BG_TILES_LO */
extern const uint8_t bg_tiles[];   /* BG_TILE_COUNT * 16 bytes, 2bpp GB format */
extern const uint8_t mt_tiles[T_COUNT][4];  /* tile numbers TL, TR, BL, BR per level cell */
extern const uint8_t mt_attr[T_COUNT][4];   /* CGB attribute per tile (palette 0-7, no flips) */

/* Font: ASCII -> BG tile number. Unmapped characters map to the blank tile.
   Required: ' ' 0-9 A-Z - . : ! ? / and the HUD icons:
   '*' star bit (coin) icon, '@' Peter's head (lives), '^' clock (time), 'x' small times sign. */
extern const uint8_t font_map[128];
#define TILE_BLANK ...             /* a tile of colour 0 only (sky) */

/* Animated BG tiles (the ? capsule's glow and the floating star bit's twinkle): the engine
   rewrites the pattern of BG tile anim_tile[i] with anim_frames[i][f] (16 bytes) every
   ANIM_PERIOD frames, cycling f = 0..ANIM_FRAMES-1. */
#define ANIM_COUNT  ...            /* <= 8 */
#define ANIM_FRAMES 4
#define ANIM_PERIOD 8
extern const uint8_t anim_tile[ANIM_COUNT];
extern const uint8_t anim_frames[ANIM_COUNT][ANIM_FRAMES][16];

/* ---- sprites (8x16 OBJ mode) ---- */
#define SPR_TILE_COUNT ...         /* <= 208 */
extern const uint8_t spr_tiles[];  /* loaded with set_sprite_data(0, SPR_TILE_COUNT, spr_tiles) */
```

The "?" block of the classic game is a **supply pod** here (a hexagonal hatch with a pulsing star
core, no question mark), and bricks are **meteorite blocks**.

Sprite frame constants are the **tile number of the top-left 8x16 object**. A 16 px wide frame
is two objects: left (`N`) and right (`N + 2`). A 16x32 frame is four: top-left `N`, top-right
`N + 2`, bottom-left `N + 4`, bottom-right `N + 6`. An 8x16 frame is one object. All frames
**face right** (the engine flips for left) and stand on the bottom pixel row of their box.
Colour 0 is transparent.

### Palettes

```c
/* CGB: 8 BG palettes and 8 OBJ palettes, 4 colours each, RGB555 */
extern const uint16_t cgb_bg_pal[8][4];
extern const uint16_t cgb_obj_pal[8][4];
#define DMG_BGP  ...
#define DMG_OBP0 ...   /* Peter, enemies, items */
#define DMG_OBP1 ...   /* the blaster suit, flashing */
```

BG palettes: `PAL_SKY 0, PAL_GROUND 1, PAL_BRICK 2, PAL_GOLD 3, PAL_TUBE 4, PAL_DECOR 5,
PAL_HUD 6, PAL_POLE 7`. Colour 0 of every BG palette is the same sky colour.

OBJ palettes: `OPAL_PETER 0, OPAL_BLASTER 1` (the blaster suit), `OPAL_GREEN 2` (Gloop,
Dome-bot, Chomper), `OPAL_RED 3` (red Dome-bot, Comet), `OPAL_ITEM 4` (power cell, flower, 1UP),
`OPAL_GOLD 5` (star bits, nova, flag), `OPAL_FX 6` (shots, shards, score), `OPAL_BLOCK 7`
(bumped brick / used capsule, matching the BG).

### Title screen

```c
#define TITLE_TILE_COUNT ...               /* <= 48, loaded at BG tile number 208 */
extern const uint8_t title_tiles[];
extern const uint8_t title_map[18][20];    /* full screen; may use font and world tiles < 128 */
extern const uint8_t title_attr[18][20];   /* CGB palettes (BG palettes above) */
```

The title shows the logo SPEEDY PURPLE PETER. The engine prints its own text (PRESS START, the
seed, the best score) in rows 11-17 with the font, so keep those rows plain sky or ground. The engine
also draws Peter sprinting in place (`SPR_PB_DASH0` / `SPR_PB_DASH1`, four objects, `OPAL_PETER`
/ OBP0) at screen x 16, y 40-71 (tile columns 2-3, rows 5-8), on the ground row, and flickers the
tail of the speed streak behind him (title map column 0, rows 5-6). The logo and its streaks are
all purple on CGB (`PAL_SKY`, `PAL_DECOR`): no gold.

## Sound (`src/gb/sound.h`)

```c
void snd_init(void);              /* APU on, master volume, silence */
void snd_tick(void);              /* once per frame, from the VBlank handler */
void sfx_play(uint8_t id);        /* SFX_* */
void music_play(uint8_t song);    /* MUS_*; MUS_NONE stops */
void music_hurry(uint8_t on);     /* 1: the "time is running out" tempo (about 1.5x) */
uint8_t music_done(void);         /* 1 when a non-looping song (jingle) has finished */
```

Songs: `MUS_NONE, MUS_MAIN` (the endless run, loops), `MUS_NOVA` (invincible, loops),
`MUS_TITLE` (loops), `MUS_DEATH` (jingle), `MUS_GAMEOVER` (jingle), `MUS_HURRY` (a short
warning jingle; the main song then resumes in hurry tempo).

Effects: `SFX_JUMP, SFX_JUMP_BIG, SFX_STOMP, SFX_KICK, SFX_BUMP, SFX_BREAK, SFX_COIN,
SFX_SPROUT` (an item rises from a capsule), `SFX_POWERUP, SFX_POWERDOWN, SFX_1UP, SFX_SHOT,
SFX_CHECKPOINT` (passing a sector checkpoint), `SFX_TICK` (one tick of the time bonus count),
`SFX_PAUSE, SFX_LAUNCH` (a comet fires), `SFX_SELECT` (menus).

All melodies are original.
